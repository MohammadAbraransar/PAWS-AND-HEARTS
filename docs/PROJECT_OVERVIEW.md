# Paws & Hearts — Project Overview

## Purpose
Paws & Hearts is a responsive pet-care and adoption discovery website. It brings pet browsing, basic care guidance, account interactions, saved pets, and adoption-request submission into one approachable interface.

## Main features
- Responsive landing page and navigation
- Pet catalogue with live text search and Dog/Cat/Other category filters
- Pet details and adoption-request form
- Browser-local account registration, sign-in, profile editing, and sign-out
- Save/favourite pets and view submitted adoption requests
- Pet care cards for nutrition, wellness, and bonding
- Newsletter signup demo
- Form validation and accessible status messages

## Technology
- HTML5, CSS3, vanilla JavaScript
- Browser `localStorage` for demo persistence
- External Unsplash images and Google Fonts are optional visual enhancements; a network connection is needed for these remote assets.

## Important limitation
This is a front-end academic prototype. It does not have a production backend. Accounts and requests are stored in the current browser only; passwords are not suitable for production storage. A real deployment should use a secure backend, hashed passwords, server-side validation, database persistence, and an authenticated adoption workflow.
